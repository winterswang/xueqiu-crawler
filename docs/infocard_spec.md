# 价值投资日报信息卡片设计规范

**版本**: V2.0  
**更新时间**: 2026-03-27 12:30

---

## 一、卡片定位

信息卡片是价值投资日报的**高密度信息摘要**，目标是让投资者在 30 秒内获取当日最有价值的投资信息。

### 核心价值

1. **决策辅助** - 安全边际、估值区间直接给出判断
2. **信息筛选** - 只展示投资相关内容，减少噪音
3. **行动导向** - 投资启示提供可操作建议

---

| 场景 | 宽度 | 高度 | 比例 |
|------|------|------|------|

| 单股卡片 | 1200px | 1600px | 3:4 |

---

## 三、内容规范（价值投资视角）

### 3.1 日报卡片

每个文章卡片包含：

| 元素 | 说明 |
|------|------|
| 标题 + 股票代码 | 明确投资标的 |
| 安全边际 | 🟢高/🟡中/🔴低 |
| 价值投资符合度 | ✅符合/⚠️部分/❌不符合 |
| 核心总结 | 一句话结论 |
| 投资启示 | 可操作建议 |

### 3.2 单股卡片

| 区域 | 内容 | 价值投资关注点 |
|------|------|----------------|
| 头部 | 名称、代码、股价、涨跌幅、市值 | 规模、市场情绪 |
| 估值指标 | PE、PB、ROE | 估值水平、盈利能力 |
| 价格区间 | 52周最高/最低 | 安全边际判断 |
| 市场观点 | 讨论中投资相关内容 | 护城河、竞争、风险 |
| 关键资讯 | 财务/估值相关新闻 | 业绩变化、行业动态 |
| 公司公告 | 年报、回购等 | 资本配置、股东回报 |

---

## 四、内容提取规则

### 4.1 讨论 - 提取投资观点

**关键词**：
- 护城河、竞争、增长、风险、估值、PE
- 利润、现金流、负债、行业、份额

**过滤**：只保留包含关键词的讨论

### 4.2 资讯 - 提取财务/估值相关

**关键词**：
- 财报、利润、营收、增长、下滑
- 业绩、估值、PE、股价、下跌、上涨、回购

### 4.3 公告 - 提取关键数据

- 年报：营收、净利润、现金流、分红
- 回购：金额、价格、时间
- 重大事项：并购、投资、业务调整

---

## 五、质量约束

### 必须包含

- [ ] 市值（规模判断）
- [ ] PE/PB（估值水平）
- [ ] ROE（盈利能力）
- [ ] 52周高低（安全边际）
- [ ] 讨论中的投资观点（≥3条）
- [ ] 财务相关资讯（≥3条）
- [ ] 公告摘要

### 禁止内容

- ❌ 无关键词的普通讨论
- ❌ 非投资相关的新闻
- ❌ 超长文字（>100字）
