# 价值投资日报·热门贴筛选优化方案（2026-11-02）

> 触发：主人反馈「热门文章质量一般，想聚焦企业分析、主题要有筛选」。
> 本文 = 现状机制说明 + 问题定位（含 11-01 实测数据）+ 可执行优化建议。**未改任何代码**，等拍板。

## 一、现状机制（hot_posts.py → generate_report.py → analyzer.py）

```
06:00 prepare job: opencli xueqiu hot 抓热榜(≤60条,5页滚动)
  → 24h 滚动窗口过滤 → 抓全文(prefetch_max=50) → score_items 打分 → top10 落 hot_top10.json
08:00 日报: 与自选账号文章按 ID 去重合并 → 同一套 LLM 分析+优先级分桶 → 价值投资日报
```

打分权重（合计 110，config.yaml `hot_posts.weights`，代码内 DEFAULT 同值）：

| 信号 | 权重 | 性质 |
|---|---|---|
| rank（热榜位次） | 30 | 平台热度 |
| freshness（新鲜度半衰 36h） | 20 | 平台热度 |
| engagement（互动量） | 20 | 平台热度 |
| watchlist（自选股 $代码$ 交集） | 15 | 内容相关 |
| followed（关注作者） | 10 | 关系信号 |
| depth（长文加分） | 5 | 内容质量 |
| topic（主题词命中） | 10 | 内容相关 |

扣分项：pnl_showoff（晒收益 −20）、volatility（择时/波动 −15，主题词 ≥4 豁免）、repeat_decay（霸榜 ×0.9）。

## 二、问题定位（2026-11-01 top10 实测）

**构成**：4 条企业分析（茅台三季报/银行股估值全览/英特尔十字路口/光启技术调研）+ **6 条杂音**（10 月投资总结、慎用杠杆反思录、「说一些按摩的话」情绪贴、印度代替参评杂感、「回复@」残缺回复贴等）。

机制根源四条：

1. **rank 底薪化**：top10 的 rank 得分集中在 25.2–29.4（满配 30）——热榜前 10 位次差异根本没拉开，rank 实际是「人人有份的 30 分底薪」，平台热度主导排序。
2. **topic 词表太泛**：company 组混有「估值/基本面/低估」级泛词（情绪贴也碰得到），命中 5 个 distinct 词即拿满 10 分——「按摩的话」贴实测 topic=10 满分。主题词没有「企业分析特征」的甄别力。
3. **主题只是加分不是门槛**：topic 不契合最多少 10 分，rank 30 + engagement 20 的高热贴照样进榜。「主题要有筛选」在现机制里没有落点。
4. **个人叙事体无信号**：pnl_showoff 只抓「晒收益金额」，「投资总结/反思录/感悟/按摩」这类自我叙事体无任何降权；「回复@」贴只把 depth 压到 0.2（=1 分），挡不住 rank+engagement 的底薪。

## 三、优化建议（三层，可独立实施）

### 层 1：机械准入门槛（hot_posts.py，~30 行，确定性最高）

select_top 之前加 gate，不满足直接进 `hot_skipped`（复用现有统计字段）：

1. **回复贴 skip**：title 或 body 以「回复@」开头（现状只降 depth，改为一票拦）
2. **个人叙事体 skip**：标题/首 80 字命中 `投资总结|月度总结|反思录|周记|心得|按摩的话|复盘日记` 等叙事模式
3. **企业分析准入线**：`$代码$` 命中或 company 强信号词（三季报/年报/调研/纪要/产能/订单/护城河等）≥2 → 准入；弱命中 → 需 watchlist 命中才准入

**11-01 离线重放验证**：gate 拦 3–4/10，留下的全是企业分析（茅台/银行/英特尔/光启/海狗），杂音仅剩「印度代替」一条灰色杂感进层 3 处理。

### 层 2：权重再平衡 + 词表升级（config.yaml 为主，零代码或微码）

| 改动 | 现值 → 建议 | 理由 |
|---|---|---|
| rank | 30 → 20 | 底薪化实证，热榜位次在前 10 内无区分度 |
| watchlist | 15 → 25 | 自选股相关是「聚焦企业分析」最硬信号，实测 10 条仅 2 条命中 |
| topic 词表 | 泛词降档 | 「估值/基本面/低估」移 philosophy 组；company 组补强信号：`$代码$`命中=强信号、「三季报/年报/调研/纪要/电话会/产能利用率/订单」 |
| 新增叙事惩罚 | penalties +15 | 标题叙事模式（与层 1 gate 二选一或并用，gate 更彻底） |

### 层 3：LLM 分析层主题分桶（analyzer prompt，~5 行）

日报生成时对融合条目先做主题分类（企业分析/行业/策略/个人叙事/行情复盘），**非企业分析直接进「🔵 参考」桶，不占 🔴必读/🟡值得关注 名额**——机械 gate 抓不住的灰色内容（如「印度代替」参评杂感）由语义层兜底。

## 四、实施与验收

- 实施顺序：层 1 → 层 2 → 层 3（每层独立可回退；config 热改，代码改动走 PR）
- 验收口径：改后第 3 天，统计连续 3 天日报中「热榜独有条目里的企业分析占比」（基线 11-01 = 4/10 = 40%，目标 ≥70%）；`hot_skipped` 中被 gate 拦截条目抽 5 条人查误杀率（目标 ≤1/5）
- 风险：门槛过严导致热榜供给不足 → top10 允许缺额（现状融合逻辑已支持 hot_total 不足，日报概览如实显示）；watchlist 权重过高导致热榜只剩自选股相关 → 层 2 上线后观察 3 天再定是否回调

## 五、改动清单（如获批准）

| 文件 | 改动 |
|---|---|
| `scripts/hot_posts.py` | gate 函数（~30 行）+ `_TOPIC_KEYWORDS` 组调整 + penalties 项 |
| `config/config.yaml` | weights 三处数值 |
| `scripts/analyzer.py`（或其 prompt 模板） | 主题分类+分桶规则 ~5 行 |
| `tests/` | gate 单测（用 11-01 top10 实测数据做夹具）+ 现有 test_hot_posts.py 回归 |
